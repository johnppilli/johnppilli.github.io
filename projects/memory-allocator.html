Memory Allocator

Complete · malloc/free, built from scratch in C

The idea

A working malloc()/free() implementation from scratch — a fixed memory pool managed by hand-written my_malloc() and my_free() — to understand what's happening underneath every heap allocation.

How it works

Manages a fixed 1024-byte pool carved into variable-sized blocks, each with a small header storing its size and free/used state. Allocation uses best-fit: scan the pool, pick the smallest free block that still fits, and split off any leftover space as a new free block. Freeing marks a block free, then coalesces it with any neighboring free block to fight fragmentation.

Proving it works

Three test cases: splitting (free a 64-byte block, allocate two 16-byte blocks, confirm both carve cleanly out of it), coalescing (free two neighboring 32-byte blocks, request a 60-byte allocation that only fits if they merged), and error handling (request more than the pool holds, confirm a clean NULL instead of a crash).
