CHIP-8 Emulator

Complete · A virtual machine, built from scratch in C

The idea

A CHIP-8 virtual machine built from scratch in C — memory model, fetch-decode-execute cycle, and graphics — with real ROMs (Pong, Tetris) actually running and playable.

Building the machine

Models CHIP-8's hardware: 4KB memory, 16 general-purpose registers, a 16-level call stack, two 60Hz hardware timers. Each 16-bit big-endian instruction gets pulled apart with bitwise masking to extract addresses, constants, and register indices across 35 opcodes.

Making it playable

Graphics run through SDL2 — sprite rendering, XOR drawing mode, pixel collision detection via the VF flag — with the hex keypad mapped to the host keyboard. Added memory bounds checking and stack overflow/underflow protection so malformed ROMs can't crash it.

Where it stands

Complete and verified — Pong and Tetris both run correctly, confirmed through actual gameplay testing.
