// systemverilog · zig · c++ · verilator

RTL Verification
Framework

Complete · Checking hardware against an independent reference model

The idea

A framework that automatically checks SystemVerilog hardware designs against independently-written Zig reference models, running both side by side and comparing their behavior cycle by cycle — since real verification means checking against an independent definition of "correct," not just trusting the RTL.

How the pipeline works

Three pieces have to agree for a test to pass: the RTL design (SystemVerilog, the same language a real ASIC/FPGA would use), the reference model (a separate "golden" implementation in Zig — if they disagree, the RTL is presumed wrong), and the testbench (C++, driving both with identical inputs every clock cycle and comparing outputs, via Verilator compiling the SystemVerilog into C++ that links with the Zig model). Verified so far: an 8-bit counter and a parameterized synchronous FIFO.

Beyond just checking the data

For the FIFO, matching output values isn't enough — it can return the right data at the wrong time and still be broken. The testbench includes a latency checker that tracks every value from write to read, recording min/max/average latency and flagging any violation, so timing gets checked as its own property.
