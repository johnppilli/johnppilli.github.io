STM32 C Control Theory I2C / ADC

02

Custom Mechanical Macro Keypad

Debugging

A custom USB macro keypad designed from schematic to fabrication in KiCad — a 3×3 matrix of 9 mechanical key switches, built around an RP2040 microcontroller.

KiCad RP2040 PCB Design USB
  • Designed a custom USB macro keypad from schematic to fabrication in KiCad: a 3x3 matrix of 9 mechanical key switches with a per-key diode on each switch to enable N-key rollover and prevent ghosting during matrix scanning
  • Drew the full schematic around an RP2040 microcontroller with a USB-C connector for power and data, USBLC6 ESD protection on the data lines, and decoupling capacitors on each supply pin
  • Routed a 2-layer PCB layout, defined the board outline (Edge.Cuts), generated Gerber and drill files, and ordered fabricated boards through JLCPCB
  • Verified the design with electrical rules check (ERC) and design rules check (DRC) in KiCad, resolving unconnected nets and clearance violations, and checked each component footprint against its datasheet land pattern before release to fabrication
  • Selected and placed supporting components around the RP2040 (crystal oscillator, voltage regulation, and decoupling) by following the microcontroller datasheet and reference design

03

CHIP-8 Emulator

Complete

A CHIP-8 virtual machine written in C, with SDL2-based graphics and input, running real CHIP-8 ROMs including Pong.

C SDL2 Emulation Bitwise Ops
  • Built a CHIP-8 virtual machine in C with 4KB memory, 16 general-purpose registers, a 16-level call stack, and hardware timers decrementing at 60Hz
  • Implemented a fetch-decode-execute cycle that parses 35 opcodes using bitwise masking to extract 12-bit addresses, 8-bit constants, and 4-bit register indices from big-endian instructions
  • Developed sprite-based graphics rendering with SDL2, supporting XOR drawing mode and pixel collision detection via the VF flag for game mechanics
  • Mapped the 16-key CHIP-8 hex keypad to host keyboard input through SDL2 events to drive interactive gameplay
  • Added memory bounds checking and stack overflow/underflow protection to prevent crashes from invalid ROM instructions, and validated correctness by running Pong and verifying expected gameplay
